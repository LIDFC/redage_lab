О проекте

ЭТО НЕ
ПРОСТО
СЕРВЕР.

RedAge v3 — это полноценная платформа для roleplay с открытым кодом. Никаких сторонних утечек, никакого ворованного кода — только чистый, структурированный проект на .NET Core и Node.js.

Архитектура разделена на src_client, src_cef и dotnet — каждый слой делает своё дело. MariaDB для данных, Redis для кэша. MongoDB не используется, и все счастливы.

// NeptuneEvo core
namespace NeptuneEvo.Core {
class RedAge {
string version = "3.0.0";
bool isAlive = true;
bool isMongoDB = false; // ✓
}
}
Возможности

ЧТО
ВНУТРИ?

Система, которую не стыдно показать коллеге. Каждый модуль — отдельная история.

🚗
01

Автосалон

Тест-драйв, подбор цвета, характеристики. Покупка за наличку или ОРГ-валюту. Реальная физика из GTA native API.

👔
02

Гардероб

Тысячи вариантов одежды, маски, очки, головные уборы. Кастомизация через CEF с превью в реальном времени.

💰
03

Экономика

Банки, наличка, RedBucks. Аукцион, переводы, зарплата. Экономика как в реальном городе — без читов и дупломбагов.

🚔
04

Фракции

LSPD, ФБИ, Армия, криминальные группировки. Звания, задания, склад оружия, война за районы.

🎒
05

Инвентарь

Drag-and-drop, стеки, быстрый доступ. Оружие, аптечки, документы, одежда — всё в одном окне.

📱
06

Телефон

SMS, звонки, такси, GPS, аукцион, новости, галерея, механик. Полноценный смартфон прямо в игре.

🏢
07

Бизнесы

24/7, АЗС, автосалоны, оружейные, барбershop, казино. Доходы, склад, заказы — управляй своей империей.

⚒️
08

Работы

Дальнобойщик, лесоруб, шахтёр, почтальон, таксист. Каждая работа — свой геймплей, не просто кружки на карте.

Установка

ЗАПУСТИ
СЕРВЕР.

Клонируй, собери, запусти. Три команды — и у тебя живой RP-сервер. Ну, почти. Не забудь настроить MariaDB и Redis.

Требуется RAGE:MP сервер
.NET 6.0+ и Node.js 16+
Visual Studio 2022 для dotnet сборки
bash — redage-setup
$
git clone https://github.com/LIDFC/redage_lab
# клонируем репозиторий
$
cd redage_lab/src_cef && npm install
# ставим зависимости интерфейса
$
npm run build
# билдим Svelte → client_packages
$
cd ../src_client && npm run build
# билдим клиентский JS
$
./ragemp-server
# 🚀 поехали
✓ Server started on port 22005
# NeptuneEvo is alive.
# dotnet: открой redage_v3-main.slnx
# собери решение в Visual Studio 2022
# скопируй resources/ на Linux сервер
